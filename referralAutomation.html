Automation Bot — Epic Navigation & Referral Logic

The automation bot searches for the patient in Epic and applies the correct referral shell logic.

🔀 Automation Bot — Referral Shell Decision Logic
✓ Patient Found + Shell Exists
  • Confirm patient demographics
  • Open existing referral shell
  • Update insurance & coverage
  • Update referring provider info
  • Refresh reason & clinical notes
  • Flag interpreter need if present
  • Upload docs to Media Manager
⊕ Patient Found + No Shell
  • Confirm patient demographics
  • No existing referral shell found
  • Create new incoming referral shell
  • Populate all intake fields
  • Set insurance & coverage
  • Flag interpreter need if present
  • Upload docs to Media Manager
⚠ Insurance Flag — Coordinator Review
  • Non-PAR insurance noted at intake
  • Referral record created and stored
  • Status set to "Pending Insurance Review"
  • Coordinator notified to verify coverage
  • All intake data & docs retained
  • Bot held until coordinator clears flag
  • Epic actions proceed once approved

AI Triage Result

🔒 Internal use only — not visible to external form submitters

What this is: When a referral is submitted, the AI engine analyses the Reason for Referral and Clinical Notes fields against the CHOP Dermatology Triage Matrix. The result — matched condition, suggested timeframe, urgency category, and confidence — is stored as dedicated columns in the SharePoint list. This data is used by the coordinator during review and passed to the automation bot when updating the Epic referral shell.

Record Updated — Referral Tracking List
The referral record is updated with Epic Shell ID, processing time, documents uploaded, and final status. The tracking list gives coordinators a real-time view of all referrals — submitted, in review, approved, processed, and flagged.
💡 Multi-device, multi-touch: Because each referral lives as a record with a unique shareable link, the back-office staff and referring provider never need to be on the same device. The provider simply opens their link when convenient — on any phone, tablet, or computer — and picks up exactly where Stage 1 left off. The workflow advances automatically based on status, not on any individual manually moving it forward.
